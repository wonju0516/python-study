# 자료구조 (Data Structure)

## 리스트 (List) — 추상 데이터 타입 vs 파이썬 구현

- **추상 데이터 타입(ADT)으로서의 리스트**: "순서가 있고, 인덱스로 접근/삽입/삭제가 가능하다"는 개념적 설계도일 뿐, 내부 구현 방식은 정해져 있지 않음
  - 배열(Array) 기반으로 구현 가능: 인덱스 접근 빠름 O(1), 중간 삽입/삭제 느림 O(n)
  - 연결 리스트(Linked List) 기반으로 구현 가능: 중간 삽입/삭제 빠름 O(1), 인덱스 접근 느림 O(n)
- **파이썬의 `list`**: 이 ADT를 실제로 구현한 결과물. 내부적으로 **동적 배열(dynamic array)** 방식이라, 인덱스 접근이 빠르고(O(1)), 여러 타입을 섞어 담을 수 있으며(이질적), 크기도 자동으로 늘어남(가변 길이)

## 정적 배열 vs 동적 배열

- **정적 배열**: 생성할 때 크기를 고정해야 하고 이후 못 바꿈 (예: C의 `int arr[5]`)
- **동적 배열**: 크기가 꽉 차면 더 큰 메모리 공간을 자동으로 잡고 기존 데이터를 복사해서 옮김. 파이썬 `list`가 이 방식
- 참고: `array` 모듈은 파이썬에서 제공하는 진짜 "동질적(한 타입만)" 배열. 문자열은 담을 수 없고 숫자 타입(`"i"`=정수, `"f"`=단정도 실수, `"d"`=배정도 실수)만 가능. **주의: 파일 이름을 `array.py`로 지으면 `import array` 시 표준 라이브러리 대신 자기 자신을 불러오는 충돌이 발생하므로 피해야 함**

## 선형 vs 비선형 자료구조

- **선형(Linear)**: 데이터가 한 줄로 순서대로 이어짐 — 배열, 리스트, 스택, 큐, 연결 리스트
- **비선형(Non-linear)**: 데이터가 여러 갈래로 뻗어나가거나 얽혀있음 — 트리, 그래프, 힙

## 리스트에 값 채워 넣는 방법 (append / insert / 인덱스 대입)

- `append(값)` / `insert(인덱스, 값)` → 리스트 **크기를 늘리면서** 새 값을 넣음
  - `append`는 맨 뒤에 추가, `insert`는 원하는 인덱스에 끼워넣기(그 자리 값은 뒤로 밀림)
- `리스트[인덱스] = 값` → 크기는 그대로 두고, **이미 있는 그 자리 값을 덮어쓰는 것(대입)**
  - 대입은 그 인덱스가 이미 존재할 때만 가능. 빈 리스트에 `evens_list[0] = 1`처럼 쓰면 `IndexError` 발생
  - 따라서 빈 리스트를 채워나갈 땐 `append`/`insert`를 써야 하고, 이미 채워진 자리 값만 바꿀 땐 인덱스 대입을 사용

## 배열 요소 삽입 시 인덱스가 흔들리는 문제 → 딕셔너리

배열(리스트) 중간에 값을 끼워 넣으면 그 뒤 요소들의 인덱스가 전부 한 칸씩 밀림.
```python
arr = ["a", "b", "c"]
arr.insert(1, "X")  # ["a", "X", "b", "c"] -> "b"가 인덱스 1 -> 2로 밀림
```
특정 값의 "자리(키)"를 고정해서 유지하고 싶다면 딕셔너리(`dict`)가 더 적합함 — key-value 짝은 다른 항목이 추가/삭제돼도 움직이지 않음.

## 0 옮기기 (배열을 순서 유지하며 in-place로 재배치)

리스트에서 0을 모두 찾아 뒤로 보내고, 나머지 요소는 원래 순서를 유지하는 문제. 새 리스트를 만들지 않고 원본 안에서 값 위치만 바꾸는(in-place) 방식.

- **한 번의 루프로 처리(투 포인터)**: `index`(읽는 포인터)와 `zero_index`(0 아닌 값을 써야 할 자리)를 같이 옮기며, 둘이 달라졌을 때만(=이미 0을 지나쳤을 때만) 원래 자리를 0으로 비움
- **두 단계로 나눠 처리(더 직관적)**: 1단계에서 0 아닌 값들을 앞으로 눌러 담고, 2단계에서 남은 뒤쪽 칸을 전부 0으로 채움
- 두 방식 모두 시간복잡도 O(n), 공간복잡도 O(1)로 동일 (루프 횟수 차이는 상수 배수라 Big-O상 무의미)
- 참고: `0`은 짝수임 (`0 % 2 == 0`)

## 리스트 결합 — zip

```python
list(zip(movie_list, ratings_list))  # 두 리스트를 튜플 쌍으로 묶은 리스트로 변환
```
`zip`은 하나 이상의 이터러블을 받아 요소를 순서대로 묶은 zip 객체를 반환하며, `list()`로 감싸 리스트로 변환해서 사용.

## set — 중복 없는 값들의 집합

- 중복을 허용하지 않고 순서가 보장되지 않는 자료구조
- `in` 연산이 리스트보다 빠름(평균 O(1) vs 리스트 O(n)) → 중복 확인, 존재 여부 확인에 적합
- 집합 연산 가능: `a & b`(교집합), `a | b`(합집합), `a - b`(차집합), `.intersection()`(2개 이상 세트도 가능: `s1.intersection(s2, s3, s4)`)

## 리스트 축약(List Comprehension)으로 교집합 구하기

```python
[v for v in list1 if v in list2]
```
`list1`을 돌면서(`for v in list1`), `list2`에도 있는 값만 골라서(`if v in list2`) 새 리스트에 담음 → 두 리스트의 교집합. `set`의 `intersection()`을 쓰면 중복 제거까지 되면서 더 빠르게 구할 수도 있음.
