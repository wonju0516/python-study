## print()

- 값을 콤마(`,`)로 나열해서 넘기면, `+`처럼 미리 하나로 합치지 않고 각 값을 그대로 넘겨서 자동으로 이어 출력해줌 (문자열이 아닌 값도 그대로 넘길 수 있음)
- `sep`: 값들 "사이"에 넣을 구분자, 기본값은 공백(`" "`)
- `end`: 출력이 다 끝난 "맨 뒤"에 붙일 문자, 기본값은 줄바꿈(`"\n"`)

```python
print("home", "user", "documents", sep="/")  # home/user/documents
print("hi", end="!! ")  # 줄바꿈 없이 "hi!! " 출력
```

## input()

- `input("질문")`은 두 가지 일을 함: 1) 괄호 안 문자열을 프롬프트로 출력  2) 사용자가 입력한 값을 문자열로 **반환(return)**
- `input()`만 단독으로 쓰면 프롬프트만 뜨고, 입력값은 반환만 될 뿐 화면에 안 찍히고 사라짐 → 입력값을 보려면 `print(input(...))`로 감싸거나 변수에 저장해야 함
- 실무에서는 `print(input(...))`처럼 바로 감싸는 경우는 드물고, 보통 변수에 저장해서 재사용함: `age = input("나이는?")`

## 문자열 포맷팅 (%, .format(), f-string)

| 방식 | 도입 시점 | 예시 |
|---|---|---|
| `%` 포맷팅 | 파이썬 초창기 | `"Hello, %s." % name` |
| `.format()` | Python 2.6 | `"Hello, {name}.".format(name=person["name"])` |
| f-string | Python 3.6 | `f"Hello, {name}."` |

- `%` 방식은 값 타입별로 다른 기호(`%s`, `%d`, `%f`)를 써야 해서 헷갈리고, 지금은 거의 안 씀
- `.format()`은 `{}` 안에 키 이름을 적고 `.format(키=값)`으로 채워 넣는 방식. `**딕셔너리`로 통째로 언패킹해서 넘길 수도 있음 (`.format(**person)` == `.format(name=person["name"], age=person["age"])`)
- f-string이 현재 표준: `{}` 안에 변수를 그대로 넣으면 되고, 타입 신경 안 써도 되고, 계산식도 바로 넣을 수 있음 (`f"{int(age)+1}"`)
- 변수를 출력에 섞을 때는 `+`로 이어붙이기보다 f-string을 쓰는 게 요즘 표준 (`+`는 문자열끼리만 가능하고 가독성이 떨어짐)

## 기본 데이터 타입 (Primitive Data Type)

- **Integer(int)**: 정수
- **Float**: 소수점이 붙은 실수 (`12.5`처럼 정수부.소수부로 구성된 하나의 숫자)
- **Boolean(bool)**: `True` / `False`
- **String(str)**: 텍스트. 따옴표로 감싼 값은 다 문자열
  - `"..."` 한 쌍 → 한 줄짜리 일반 문자열. 소스코드 안에서 실제로 Enter를 쳐서 줄을 나누면 `SyntaxError`가 남
  - `"""..."""` (큰따옴표 3개) → 여러 줄 문자열(multi-line string), 줄바꿈을 그대로 포함해서 저장 가능
  - `\n`은 "줄바꿈 문자"를 뜻하는 이스케이프 시퀀스일 뿐이라, 한 줄짜리 `"..."` 안에서도 자유롭게 쓸 수 있음 (`"Cisca\nOladipo"`는 정상 동작)

## 사칙연산 (Mathematical Operation)

| 연산자 | 의미 | 예시 |
|---|---|---|
| `/` | 나눗셈 (float 반환) | `3 / 2` → `1.5` |
| `//` | 몫만 반환 (float division) | `3 // 2` → `1` |
| `**` | 거듭제곱 | `3**3` → `27` |
| `%` | 나머지 (모듈로) | `60 % 13` → `8` |

- `%`(나머지 연산자)는 정수뿐 아니라 실수(float)에도 그대로 적용 가능 (`12.5 % 5.5` → `1.5`)

## 조건문 (Conditional Expression)

- `elif`는 조건들이 서로 **배타적**이라, 위에서부터 순서대로 검사하다가 하나라도 참이면 그 즉시 나머지는 검사 안 하고 딱 하나만 실행됨
- 중첩 if(nested if)는 바깥 조건을 통과한 뒤, 그 안에서 **독립적인** 여러 조건을 각각 따로 검사 → 조건이 여러 개 동시에 만족되면 그만큼 다 실행될 수 있음

```python
# elif: my_money=100이면 "20 초과"만 출력되고 끝
if my_money > 20:
    print("20 초과")
elif my_money > 10:
    print("10 초과")

# 중첩 if: my_money=100이면 두 print가 다 실행됨
if my_money > 0:
    if my_money > 10:
        print("10 초과")
    if my_money > 20:
        print("20 초과")
```

"여러 조건 중 하나만 골라서 실행"하고 싶으면 `elif`, "바깥 조건을 통과한 뒤 추가로 또 다른 조건들을 따로따로 확인"하고 싶으면 중첩 `if`를 사용.

## 논리 연산자 (Logical Operator)

| 연산자 | 의미 |
|---|---|
| `A and B` | 두 조건 모두 참이어야 `True` |
| `X or Y` | 둘 중 하나라도 참이면 `True` |
| `not E` | 참/거짓을 뒤집음 |

- `isinstance(값, 타입)`: 값이 특정 타입인지 확인하는 내장 함수. `isinstance(10, int)` → `True`, 타입을 튜플로 여러 개 넘기면(`isinstance(10, (int, float))`) 그중 하나라도 맞으면 `True`
- 조건문에서 `and`와 함께 자주 씀 — 값이 특정 타입인지 먼저 확인한 뒤에만 다음 조건(비교 연산 등)을 검사해서, 타입이 안 맞을 때 에러 나는 걸 방지 (`isinstance(value, int) and value > 5`)

## random 모듈

| 함수 | 하는 일 |
|---|---|
| `random.randint(a, b)` | a부터 b까지(양 끝 포함) 정수 하나 랜덤 |
| `random.random()` | 0.0 이상 1.0 미만 실수 하나 랜덤 |
| `random.randrange(a, b)` | `range(a, b)`처럼 b는 제외하고 랜덤 정수 |
| `random.uniform(a, b)` | a부터 b 사이 실수 랜덤 |
| `random.choice(리스트)` | 리스트에서 원소 하나 랜덤으로 뽑기 |
| `random.sample(리스트, n)` | 리스트에서 중복 없이 n개 랜덤으로 뽑기 |
| `random.shuffle(리스트)` | 리스트 순서를 그 자리에서 랜덤으로 섞음 (반환값 없음, 원본 변경) |

- `randint(1, 10)`은 10을 **포함**, `randrange(1, 10)`은 10을 **제외** — 헷갈리기 쉬운 부분
- `choice`는 하나만, `sample`은 여러 개를 중복 없이 뽑음 (로또 번호 뽑기 같은 상황엔 `sample`)
- 활용 예: 0~10 사이 랜덤 정수를 짝/홀로 나눠서 동전 앞뒤(head/tail) 시뮬레이션하기 (`coin.py`)
