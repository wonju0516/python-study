# 초심자가 꼭 알아야할 점 (python_internals)

## 얕은 복사 vs 깊은 복사 (`copy_deep_shallow.py`)

- **`b = a`(대입)**: 복사가 아님. `b`와 `a`가 메모리상 **완전히 같은 객체**를 가리키게 될 뿐이라, 어느 쪽을 바꿔도 서로 영향을 줌
- **compound object(합성 객체)**: 다른 객체에 대한 참조(포인터)를 담고 있는 객체 (리스트, 딕셔너리 등). 숫자/문자열처럼 참조를 안 담는 값은 해당 안 됨
- **얕은 복사(`a[:]`, `copy.copy()`)**: 바깥 리스트(껍데기)만 새로 만들고, 안에 들어있는 원소가 compound object면 원본과 **같은 객체를 그대로 참조**함
  - 그래서 바깥에 새 원소를 추가(`b.append(...)`)해도 원본엔 영향 없지만, 안쪽 원소를 직접 수정(`b[0].append(...)`)하면 원본도 같이 바뀜
  - 단, 원소가 숫자처럼 단순 값(atomic)이면 애초에 공유할 안쪽 객체가 없어서, 얕은 복사만으로도 완전히 독립적인 복사가 됨
- **깊은 복사(`copy.deepcopy()`)**: 바깥 리스트뿐 아니라 안의 원소들까지 재귀적으로 전부 새로 복사 → 원본과 완전히 분리됨

## 스코프 (`scope.py`)

- **local / global / enclosing scope**: 각각 지금 함수 안 / 파일 최상단(함수 밖) / 함수 안에 또 함수가 있을 때 바깥 함수의 지역 스코프
- **namespace**: "이름(변수명) → 값"을 연결해주는 장부. global/local이 각각 별도의 장부라 같은 이름이 있어도 안 겹침
- **`if`/`for`/`while`은 새 스코프를 안 만듦** — 함수(`def`)만 새 스코프를 만듦. 그래서 `if` 블록 안에서 바꾼 변수도 진짜 전역/지역 변수 그 자체가 바뀜
- **`global`**: 함수 안에서 "이 이름은 전역 변수를 가리켜라"라고 선언. 없으면 함수 안에서 대입(`=`)한 순간 자동으로 새 지역 변수가 됨 (전역은 안 바뀜)
- **`nonlocal`**: `global`과 같은 역할이지만 대상이 "한 단계 바깥 함수(enclosing scope)"인 경우. 없으면 안쪽 함수의 대입은 새 지역 변수를 만들 뿐, 바깥 함수의 변수는 그대로임
- **대입(`=`) vs 메서드 호출(`.append()` 등)**: 대입은 새 지역 변수를 만들지만, `.append()`처럼 이름을 새로 만들지 않고 그 이름이 가리키는 객체 자체를 수정하는 건 지역 변수가 안 생기고 LEGB로 찾은 원본을 그대로 건드림
- **LEGB 규칙**: 변수 이름을 찾는 순서 = **L**ocal → **E**nclosing → **G**lobal → **B**uilt-in. 가장 먼저 찾은 곳의 값을 씀
- **`globals()`**: `global` 키워드가 아니라, 현재 전역 namespace를 딕셔너리로 보여주는 내장 함수
- **전역 스코프는 언제 쓰나**: 반복해서 쓰는 상수를 한 곳에 모아둘 때 유용. 값을 자꾸 바꾸는 용도로 쓰는 건 지양 — 함수는 인자로 받고 return으로 돌려주는 게 더 안전함

## 코드를 짧게 줄이는 better solution 모음 (`errors.py`)

| 원래 코드 | better solution | 왜 나은지 |
|---|---|---|
| `if is_correct == True: return True else: return False` | `return is_correct` | 이미 불리언인 값을 굳이 다시 `True`와 비교/분기할 필요 없음 |
| 반복문으로 합계 누적 | `sum(리스트)` | 내장 함수라 한 줄로 끝나고 실수할 여지가 적음 |
| `math.inf`를 초기값으로 잡고 반복문으로 최솟값 탐색 | `min(리스트)` / `max(리스트)` | 초기값 설정 실수 위험 없이 더 간단함 |
| 반복문으로 합계 구해서 나누기 | `numpy.mean(리스트)` | 최적화되어 있어 대용량 데이터에서 더 빠르고 간결함 |

- `math.inf`는 **양의 무한대**. 어떤 숫자든 이보다 작으므로 최솟값 탐색의 초기값으로 안전함 (음수만 있는 리스트에서도 문제없음)
- **`sort()` vs `sorted()`**: `.sort()`는 원본을 직접 정렬하고 **반환값이 없음(`None`)** → `print(l1.sort())`를 하면 `None`이 찍힘. `sorted()`는 원본은 그대로 두고 정렬된 **새 리스트를 반환**함
